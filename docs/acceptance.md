## 场景与预期行为

| 编号 | 场景/输入 | 必须观察到的结果 | 对应需求 |
| --- | --- | --- | --- |
| A-01 | 已授权客户端与正确核心公钥 | 认证成功，取得允许的地址与路由；未经确认不开始发数据 | FR-01、02、23 |
| A-02 | 未知公钥、错误私钥或核心身份不匹配 | 不建立隧道、不接收该 peer 数据、不泄漏绑定秘密 | FR-01、02 |
| A-03 | 将认证/BIND 材料重放到其他连接、session 或 peer | 拒绝绑定，其他合法会话继续工作 | FR-05 |
| A-04 | 删除正在使用的 peer 授权 | 生效后已有会话关闭，新连接和新路径均被拒绝 | FR-01、02 |
| A-05 | 同一公钥重复建连/并发进程 | 按冻结后的并发策略处理，不出现地址抢占或误绑定 | FR-02、05、23 |
| A-06 | 同一包经 K 条路径到达，顺序任意 | 最先到达的有效副本立即交付，总交付次数为 1 | FR-08、09、10 |
| A-07 | 窗口内乱序、窗口外旧包、序号耗尽 | 按已定义窗口规则处理，不重复交付，不允许序号无保护回绕 | FR-09 |
| A-08 | K≥2 时黑洞一条发送路径，其他路径无额外丢包且容量足够 | 健康路径继续传输，session 不重置，不因等待故障路径造成丢包 | FR-10、11、18 |
| A-09 | 仅一条路径队列被填满 | 其他路径不阻塞，丢弃计数可解释，内存不超冻结预算 | FR-11、26 |
| A-10 | 全部路径断开后恢复 | 报告断连；缓存有界；按冻结的 session 保留/重建规则恢复 | FR-07、18、19 |
| A-11 | NAT 重绑定、客户端切换网络、边缘地址变化 | 验证新路径；可迁移时迁移，否则重建并绑定；不得绕过认证 | FR-04、05、07 |
| A-12 | 核心进程重启 | 客户端重新认证；旧 session 消息无效；不假装 NAT/业务连接仍连续 | FR-02、05、07 |
| A-13 | SET 请求或响应重复、延迟、跨路径乱序 | 请求幂等；旧版本不覆盖新版本；双方最终确认同一有效状态 | FR-13、14、19 |
| A-14 | SET 切换时旧路径同时故障 | 状态更新不出现软件造成的空发送集合；紧急摘除结果可恢复一致 | FR-14、18、19 |
| A-15 | K 高于健康路径数、预算不足或核心限制 | 实际 K 与原因可观测；不复制到同一路径冒充冗余 | FR-10、13、25 |
| A-16 | RTT 短时尖峰、路径恢复及反复抖动 | 按冻结的迟滞和恢复条件切换；不无限振荡 | FR-15、18 |
| A-17 | 未被选中路径长时间空闲 | NAT 映射按计划维持，重新选中前具备有效健康证据 | FR-20、22 |
| A-18 | 不同路径最大 DATAGRAM 不一致且传输中降低 | 每份副本符合路径限制，按 MTU 设计降级/报错，不无声黑洞 | FR-12 |
| A-19 | 内层 IPv6 包在小 MTU 外层路径上传输 | 满足冻结的 IPv6 支持及最小 MTU 策略；无法满足时明确拒绝或降级 | FR-12、23 |
| A-20 | 冒用其他 peer 源地址、访问未授权前缀 | 拒绝转发，日志/计数可识别原因，不越权访问 | FR-23、24 |
| A-21 | 全隧道路由与隧道外层目的地址冲突 | 外层绕过 TUN；无路由递归；冲突可在配置阶段诊断 | FR-23、24 |
| A-22 | 配置更新有误，或系统规则更新中途失败 | 当前有效配置保留，已执行改动按设计回滚，不破坏原有规则 | FR-23、24、25 |
| A-23 | 正常退出、异常退出后重启 | 自有规则可识别和恢复/清理；不删除用户其他网络配置 | FR-23、24 |
| A-24 | 超长控制消息、握手洪泛、超限路径及慢速发送 | 有界资源、明确拒绝/超时行为；合法 peer 资源受保护 | FR-02、05、11、19 |
| A-25 | 发送 API 成功但包未被应用接收 | 不将 API 成功或传输 ACK 当作最终交付成功 | FR-20、21、26 |
| A-26 | 日志、错误与配置诊断输出 | 不含私钥、会话秘密或默认的用户包载荷；可关联 peer/session/path | FR-26、27 |
| A-27 | K=1/2/3，同硬件、同业务负载及同链路条件 | 分别报告有效业务流量、外层流量、CPU、内存、包率与尾延迟 | 非功能性能、FR-25、26 |
| A-28 | 普通浏览器/未授权客户端访问 HTTP/3 服务 | 若首版选此功能，应获得规定的网站行为；不能因此获得隧道权限 | FR-03 |
| A-29 | 协议版本不兼容、未知必需能力、未知可选字段 | 按冻结兼容规则拒绝或忽略，错误可诊断；禁止静默降级安全属性 | 协议兼容设计 |
